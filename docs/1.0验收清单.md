# 脑力训练 1.0 验收记录

日期：2026 年 10 月 7 日。范围为 Flutter 3.35.7 下的 24 款训练合集源码，以及 GitHub Android 工程生成与 APK 校验配置。

## 已完成的功能

24 个独立训练项目，六类能力各四项；每项十个可选等级。三页导航、分类与搜索、玩法说明、倒计时、观察／作答阶段、反馈、成绩、再练一次、暂停、退出确认均已实现。

设置、最近 20 次记录、最佳成绩和上次等级使用 Android 本地 SharedPreferences 保存。JSON 写入顺序有保证，异常记录可隔离，写入失败保留当前可见成绩。音效与触觉反馈可关闭。原生读写在线程池中执行，无网络服务、账号或数据库。

启动图标为本地矢量图，训练图形由 Flutter 绘制。已检查 lib 中不包含 HTTP、网络图片或 Socket 调用。APK 验证保留 INTERNET 权限检查、最低 API 24 和固定签名检查；系统云备份关闭。

## 自动检查覆盖

- 所有游戏十级生成参数，23 个生成器各检查 20 个随机种子，共 4600 个题目；反应速度另检查十级响应边界。
- 迷宫与拼块分别额外检查 400 个题目，验证可达、合法最短路线、覆盖无重叠及拼块连通。
- 图形镜像与旋转候选不会产生多个合法旋转答案。
- 算术优先级、括号、负数、整除、不可除零和不完整表达式；凑数目标有合法解，卡片不能重复使用或直接拼接。
- 数字隐藏、卡片配对、位置提交、顺序复现、排序、拼块、路径、抑制反应与节奏的操作检查。
- 每款生成器的 Level 1、5、10 在 360×800 屏幕渲染；主界面另检查 320×640 和字体放大。
- 连点单次结算、抢跑、超时、暂停保留、计时排除后台时间、重开与资源释放。
- 本地数据重启恢复、等级最佳区分、最多 20 条历史、损坏记录、写入失败及原生通道协议。
- Android 工程生成、原生文件及图标注入、固定签名配置、网络权限移除、APK API 与证书校验。

本地结果：43 项 Flutter 测试全部通过，13 项 Python 工程与校验测试通过，flutter analyze 显示 No issues found。另已渲染并检查首页、训练库、高级数字记忆和成绩页。CI 中继续执行代码分析、Flutter 测试和 Python 测试。
