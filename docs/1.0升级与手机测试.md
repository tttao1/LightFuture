# 升级到脑力训练 1.0

原反应速度 Demo 已经在你的手机验证。此次源码扩展为 24 款训练合集，新增完整三页界面、本机持久记录、音效与原创启动图标。

## 上传哪些文件

下载并解压 dist/lightfuture-1.0.0-source.zip。压缩包中的文件直接对应 GitHub 仓库根目录，不需要再套一层 LightFuture。

请覆盖上传整个 lib、test、tool、docs 目录，以及 pubspec.yaml、pubspec.lock、analysis_options.yaml、README.md。现有 .github/workflows/android-apk.yml 可以继续使用；完整源码包也包含该文件。

特别确认 tool/android/MainActivity.kt 与 training_icon.xml 已上传。它们提供手机上的 SharedPreferences 保存、音效与图标，不能只更新 Dart 文件。不要重新生成 tool/demo-signing 中的签名文件。

网页操作：Code → Add file → Upload files，在仓库根目录拖入上述目录和文件，提交到 main。对隐藏的 .github 可继续使用网页 Create new file 的方式；已存在且内容相同的工作流无需重建。

## 打包和覆盖安装

1. 提交后进入 Actions，打开最新的 Build Android Demo APK 运行记录。
2. 等 Python 检查、Flutter 分析及测试、APK 构建和校验全部通过。
3. 从 Artifacts 下载 lightfuture-demo.apk。
4. 手机直接点击 APK，覆盖安装原 Demo。包名与签名保持不变，构建编号随 Actions 递增。
5. 安装完成后打开“脑力训练”，版本 1.0.0，检查底部有“首页、训练、我的”。

APK 文件名为兼容现有下载流程仍保留 demo；功能和界面已经是完整合集。源码包不是安装包，需先云端构建 APK。

## 建议先测试

- 数字记忆：数字隐藏后作答，Level 10 加入颜色、位置和背景干扰，只复述数字。
- 舒尔特方格：数字按顺序点击；点错有反馈但不推进目标。
- 原反应速度：和之前 Demo 相同，正常、抢跑、超时及再次训练都能运行。
- 我的：关闭音效／振动，再杀进程启动，确认设置、最近记录和最佳成绩恢复。
- 任意普通游戏进行到一半，切后台再回来；继续倒计时后应保留操作进度。
- 反应／节奏游戏切后台后，当前未完成轮次重新准备，已完成轮次保留。

再覆盖试玩六类能力中的其余项目。卡片配对、节奏、拼块和路径是单局完整挑战；其余多数为五轮，抑制反应为十轮。拼块可长按拖放，也可先选择再点锚点，调整时取回；路径可滑动，也可逐格点选。

## 离线确认

启用飞行模式并关闭 Wi-Fi，彻底杀掉 App 后重新启动，分别完成六类训练，确认无需下载素材或题库。用清除本机记录按钮时需确认，清除后音效与振动设置仍保留。

如果发现问题，反馈游戏名称、等级、手机型号、Android 版本、该次构建编号及操作步骤。测试已覆盖代码和题目有效性，完整合集的真机体验仍以此次安装为准。
